# Power BI Sales Dashboard

An interactive sales dashboard built in Power BI Desktop from raw sales
data. It breaks revenue down by supervisor, product and region, with KPI
cards, bar and pie charts, and a map view — one page that answers who
sold the most, which products lead, and which regions lag.

## What's inside

- `SALESDASHBOARD.pbix` — the dashboard file. Open it in Power BI
  Desktop (free from Microsoft). Data was cleaned in Power Query, and
  the supervisor and sales tables are modelled so the visuals stay
  linked.

## How to open

1. Install Power BI Desktop.
2. Open `SALESDASHBOARD.pbix`.
3. If the map visual shows an error, go to File > Options > Global >
   Security, enable Map and filled map visuals, then fully restart
   Power BI Desktop.

## Tools

Power BI, Power Query, DAX, Excel
